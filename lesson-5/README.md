AWS Infrastructure with Terraform (Lesson 5)
Цей проєкт створює базову інфраструктуру в AWS за допомогою модульної структури Terraform.

Структура проєкту
modules/s3-backend: Створює S3 бакет для зберігання стейт-файлів та DynamoDB для блокування.

modules/vpc: Створює мережу (VPC) з 3 публічними та 3 приватними підмережами, Internet Gateway та NAT Gateway.

modules/ecr: Створює Elastic Container Registry для зберігання Docker-образів із увімкненим скануванням.

Початок роботи
1. Ініціалізація (Локальний стейт)
Оскільки бекенд створюється в цьому ж проєкті, перший запуск має бути локальним. Тимчасово закоментуйте вміст файлу backend.tf і виконайте команди:

terraform init

terraform plan

terraform apply

2. Міграція стейту в S3
Після того, як S3 та DynamoDB будуть створені:

Розкоментуйте вміст файлу backend.tf.

Виконайте команду для міграції:

terraform init -migrate-state

На запитання про копіювання стейту дайте відповідь yes.

Основні команди
terraform plan — перегляд запланованих змін.

terraform apply — застосування конфігурації.

terraform destroy — видалення всієї створеної інфраструктури.

Вихідні дані (Outputs)
Після успішного завершення ви отримаєте:

vpc_id: Ідентифікатор створеної мережі.

ecr_repository_url: Адреса вашого репозиторію для Docker-образів.

s3_bucket_name: Ім'я бакета зі стейтом.
